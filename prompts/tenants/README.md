# Per-tenant chat briefs

`EXISTING-TENANT.md` carries what is true for every tenant: the house
rule, the migration ledger, the security facts, the timestamp rule, the
100-character commit limit. It cannot carry what is true for **one**
tenant this week.

These files do. Open the chat **inside that tenant's folder**, paste
`EXISTING-TENANT.md`, then paste the brief for that tenant.
